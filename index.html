📖 AI Agent 安装教程

通用三步: ① 装命令行(需 Node 18+ / Python 3.10+, 可在左侧「语言」栏先装)→ ② 配 API Key 或登录 → ③ 在项目目录启动。

0 · 第一次先检查环境

node -v           # 缺: winget install OpenJS.NodeJS.LTS
python --version  # 缺: winget install Python.Python.3.12
git --version     # 缺: winget install Git.Git

装完 重开 PowerShell 再继续。

1 · 一键自动安装(推荐)

项目目录自带 install_agents.ps1, 或点本面板右上角「⚡ 自动安装」复制命令。运行后: 自动补装缺失环境 → 选分类(1终端/2IDE/3本地/4框架)→ 勾编号 → 自动装完并校验。

cd D:\zcode\code-lab
powershell -ExecutionPolicy Bypass -File .\install_agents.ps1
# 常用参数:
#   -List                  只列出 28 款及安装状态
#   -Agents kimi,cursor    按名称/关键词安装
#   -All                   一键装全部(网页型自动开官网)

2 · 网页手动安装

点每张卡片「复制」拿安装命令, 粘到 PowerShell 回车。npm install -g … 终端型 / python -m pip install … Aider·LangGraph·CrewAI / winget install … Cursor·Windsurf·Ollama / code --install-extension … IDE 插件型。

3 · 装完: 登录 / 配 Key / 启动

  • Claude Code: claude 登录 Anthropic; Codex: codex 用 ChatGPT 账号; Kimi: kimi 选 Kimi Code OAuth; Qwen: qwen 通义 OAuth(免费 2000/天)
  • API Key 型: 官网控制台申请 Key, 设 $env:OPENAI_API_KEY="sk-..." 或永久写入用户环境变量
  • IDE 插件型: 装完扩展在 VSCode 侧边栏点开, 手机号/云账号登录, 多数有免费额度
  • 本地模型: ollama pull qwen2.5:7b, 或 LM Studio 下载模型

4 · 常见问题

  • npm 慢/超时: npm config set registry https://registry.npmmirror.com
  • code 不是命令: VSCode 内 Ctrl+Shift+P → Shell Command: Install 'code' command in PATH
  • winget 找不到: winget search 工具名 核对后安装
  • 装完没命令: 重开 PowerShell / VSCode(PATH 刷新)
  • 国产全家桶(通义灵码/CodeGeeX/Comate/CodeBuddy/码道/Trae/Kimi/Qwen/扣子)免翻墙; 海外工具部分地区可能慢
